Featured — Systems

x86-64 Emulator & Debugger

View source →

A from-scratch x86-64 emulator in modern C++ — no dependency on an existing CPU-emulation library. Decodes real machine code, loads real ELF binaries, and enforces flag correctness the way silicon does.

01
Decode

Raw byte streams into instruction semantics — prefixes, ModRM/SIB, and operand encoding handled explicitly, no third-party disassembler.

02
Execute

CPU state, integer flags, virtual memory and syscalls, with an ELF loader that maps real binaries into emulated address space.

03
Verify

Unit tests assert flag correctness per the Intel SDM for every implemented instruction, ahead of a planned JIT backend.
